# BG-Repository

BG-Repository is a Kodi add-on repository for selected add-ons.

Install the repository in Kodi using the ZIP for your generation:

```text
Kodi Omega: https://blauesgruen.github.io/BG-Repository/omega/repository.bg/repository.bg-0.3.1.zip
Kodi Piers: https://blauesgruen.github.io/BG-Repository/piers/repository.bg/repository.bg-0.4.0.zip
```

The add-on ID remains `repository.bg`. Each feed publishes its own repository version in `addons.xml` for Kodi's normal update mechanism. An installed 0.3.0 on Piers that only knows the Omega feed requires one manual ZIP update.

Releases are available here:

```text
https://github.com/blauesgruen/BG-Repository/releases
```

Currently included:

```text
pvr.satip for Kodi Omega and Piers
```

More add-ons may be added later.
